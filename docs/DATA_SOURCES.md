# RainGuard 확정 공공데이터 출처

이 문서는 제안서와 결과보고서에 실제로 사용할 수 있는 공식 데이터만 정리한 문서입니다. 현재 RainGuard는 임의 침수 지점 CSV를 사용하지 않고, 서울안전누리의 공식 침수흔적도 WMS 레이어를 지도에 표시하는 방향으로 수정했습니다.

## 1. 서울안전누리 침수흔적도

- 출처: 서울안전누리
- 접근 경로: 안전정보지도 > 태풍·호우 > 침수흔적도
- URL: https://safecity.seoul.go.kr/distFclt/cfMapDs/cfMapDs.page?menuId=MENU_SSNS_000014
- 확인한 레이어: `수방 침수흔적도 2010`, `2011`, `2012`, `2013`, `2014`, `2016`, `2017`, `2018`, `2019`, `2020`, `2022`, `2023`, `2024`, `2025`
- RainGuard 활용:
  - 과거 침수 발생 위치를 지도 위에 시각화한다.
  - 이후 격자별 침수 이력 라벨 또는 침수 지역과의 거리 feature로 활용한다.
  - 제안서 캡처에서는 2022년 침수흔적도를 기본 예시로 사용한다.

## 2. 기상청 단기예보 조회서비스

- 출처: 공공데이터포털 / 기상청
- 서비스명: 기상청_단기예보 조회서비스
- URL: https://www.data.go.kr/data/15084084/openapi.do
- 제공 형식: REST API, JSON/XML
- 주요 활용값:
  - 초단기실황 `RN1`: 1시간 강수량
  - 초단기예보/단기예보 강수 관련 예보값
- RainGuard 활용:
  - 현재 MVP는 `10mm/h`, `30mm/h`, `50mm/h` 강수량 시나리오로 시연한다.
  - 실제 서비스 단계에서는 기상청 API의 강수량 값을 자동 반영한다.
  - RandomForest 모델 학습 시 강수량 feature로 사용한다.

## 현재 제외한 데이터

아직 실제 확보 또는 사용 경로가 확정되지 않은 데이터는 제안서의 핵심 데이터로 쓰지 않습니다. 도로망, 행정구역, 주소 검색 데이터는 결과보고서 구현 단계에서 공식 출처를 확정한 뒤 추가합니다.

## 제안서에 쓸 문장

본 프로젝트는 서울안전누리 안전정보지도에서 제공하는 태풍·호우 분야의 침수흔적도와 기상청 단기예보 조회서비스의 강수량 데이터를 활용한다. 침수흔적도는 과거 침수 발생 지역을 지도화하고 AI 모델의 학습 라벨 및 위험도 산정 기준으로 사용하며, 강수량 데이터는 폭우 상황별 침수 위험도 예측 feature로 활용한다.
