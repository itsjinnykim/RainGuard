# RainGuard 공공데이터 출처 후보

이 문서는 제안서와 결과보고서에 사용할 데이터 출처 후보를 정리한 문서입니다.

## 1. 침수 위험 / 침수 이력 데이터

### 생활안전정보 오픈API

- URL: https://www.safemap.go.kr/dvct/openAPIRenew.do
- 용도: 생활안전지도 기반 재난·안전 관련 공간정보 후보
- 확인 내용:
  - 생활안전정보는 생활안전지도의 다양한 콘텐츠와 데이터를 쉽게 이용할 수 있도록 오픈API 서비스와 기술을 제공한다고 안내함.
  - 오픈API 활용을 위해 인증키 발급이 필요함.
- RainGuard 활용 계획:
  - 침수흔적도 또는 풍수해 관련 공간 데이터가 제공되는지 확인한다.
  - 제공 가능하면 과거 침수 발생 지역을 지도 라벨과 AI 학습 라벨로 활용한다.

### 서울 열린데이터광장

- URL: https://data.seoul.go.kr/dataList/datasetList.do
- 용도: 서울시 행정구역, 안전, 지도, 도시 인프라 관련 데이터 탐색
- 확인 내용:
  - 서울 열린데이터광장은 공공데이터, 통계, 지도형 데이터 등을 제공한다.
  - 안전 카테고리와 MAP 제공 유형이 있어 서울시 안전·공간 데이터 탐색 후보로 적합하다.
- RainGuard 활용 계획:
  - 서울시 침수 관련 데이터, 빗물펌프장, 하수관로, 침수취약지역, 행정동 경계 등을 탐색한다.

## 2. 강수량 / 강수 예보 데이터

### 기상청 단기예보 조회서비스

- URL: https://www.data.go.kr/data/15084084/openapi.do
- 제공기관: 기상청
- 형식: REST API, JSON/XML
- 용도: 강수량 또는 강수 예보 feature 생성
- 확인 내용:
  - 초단기실황, 초단기예보, 단기예보 정보를 제공한다.
  - 업데이트 주기는 실시간이며, 개발 단계 활용신청은 자동승인이다.
  - 초단기실황 조회 기능에서 `RN1` 항목이 1시간 강수량 계열 값으로 사용 가능하다.
- RainGuard 활용 계획:
  - MVP에서는 `10mm/h`, `30mm/h`, `50mm/h` 시나리오를 사용한다.
  - 실제 서비스에서는 기상청 API의 강수량 값을 자동 반영한다.

## 3. 지도 / 행정구역 / 공간 기반 데이터

### 브이월드 오픈API

- URL: https://www.vworld.kr/v4po_openapi_s001.do
- 제공기관: 국토교통부 계열 디지털트윈국토 서비스
- 용도: 배경지도, 주소 검색, 국가공간정보 API 후보
- 확인 내용:
  - 국가 공간정보를 개방·공유하고, 2D/3D 및 검색 관련 오픈API를 제공한다.
  - 지도 생성을 위한 인증키 발급이 필요하다.
- RainGuard 활용 계획:
  - 행정구역 경계, 주소 검색, 지도 기반 시각화 고도화에 활용 가능성을 검토한다.

## 4. 도로망 / 경로 계산 데이터

### OpenStreetMap

- URL: https://www.openstreetmap.org/copyright
- 용도: 도로망 데이터 및 경로 계산 후보
- 확인 내용:
  - OpenStreetMap은 전 세계 도로, 길, 시설 등 오픈 지도 데이터를 제공한다.
  - ODbL 라이선스로 제공되며, OpenStreetMap 출처 표시가 필요하다.
- RainGuard 활용 계획:
  - `osmnx`, `networkx` 등을 사용해 강남구 도로망을 불러온다.
  - 도로 구간별 침수 위험 점수를 반영해 안전경로를 계산한다.

## 제안서에 쓸 문장

본 프로젝트는 서울시 및 생활안전정보의 재난·안전 공간 데이터, 기상청 강수량 데이터, 지도 및 도로망 데이터를 결합하여 도시 침수 위험도를 산정한다. 초기 MVP는 강수량 시나리오 기반으로 위험도를 시각화하며, 향후 침수흔적도와 도로망 데이터를 반영해 RandomForest 기반 격자별 침수 위험 예측 및 안전경로 추천 기능으로 고도화한다.
