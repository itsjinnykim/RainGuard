# RainGuard 제안서 1페이지 초안

## 제목

공공데이터 기반 도시 침수 위험 예측 및 안전 이동 경로 추천 서비스

## 부제

폭우 상황에서 최단경로가 아닌 안전경로를 추천하다

## 문제 정의

기존 지도 서비스는 빠른 길을 알려주지만, 폭우 상황에서 그 길이 안전한지는 알려주지 않는다. 도심 지역은 지하차도, 저지대 도로, 배수 취약 구간 등으로 인해 짧은 시간의 강한 비에도 이동 중 침수 위험이 발생할 수 있다.

## 서비스 개요

RainGuard는 공공데이터를 기반으로 침수 위험도를 지도 위에 시각화하고, 향후 위험 구간을 우회하는 안전 이동 경로를 추천하는 서비스다. 제안서 단계에서는 강수량 시나리오에 따른 침수 위험도 지도 MVP를 구현하고, 결과보고서 단계에서는 AI 모델과 경로 추천 기능을 고도화한다.

## 활용 데이터

| 데이터 | 활용 목적 |
| --- | --- |
| 침수흔적도 / 침수위험 공간정보 | 과거 침수 이력 및 학습 라벨 생성 |
| 기상청 강수량 / 단기예보 | 강수량 feature 및 시나리오 입력 |
| 도로망 데이터 | 최단경로 및 안전경로 계산 |
| 행정구역 / 지도 데이터 | 분석 지역 필터링 및 지도 시각화 |

## AI 적용 계획

격자 단위로 강수량, 과거 침수 이력, 침수 지역과의 거리, 도로 밀도 등을 feature로 생성하고, RandomForest 모델을 사용해 침수 위험 확률을 예측한다. 침수 예측에서는 위험 지역을 놓치지 않는 것이 중요하므로 Recall을 주요 지표로 활용한다.

## 경로 추천 방식

도로 구간별 침수 위험도를 비용에 반영한다.

```text
최종 경로 비용 = 도로 길이 x (1 + alpha x 침수 위험도)
```

위험도가 높은 도로는 실제 거리보다 더 비싸게 계산되어, 경로 탐색 과정에서 자연스럽게 우회되도록 한다.

## 현재 MVP

- Streamlit 기반 웹앱 배포
- 강수량 시나리오 선택
- 침수 위험도 카드 표시
- Folium 지도 기반 위험 구역 시각화
- 향후 실제 침수흔적도 데이터로 샘플 지점 교체 예정

## 기대효과

폭우 상황에서 시민의 이동 안전성을 높이고, 도시 침수 위험 정보를 직관적으로 제공한다. 또한 지자체의 침수 대응, 사전 경보, 안전 이동 안내 서비스로 확장 가능하다.
