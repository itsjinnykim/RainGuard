# RainGuard 대표 시연 경로 평가

평가일: 2026-07-07  
테스트 조건: 강수량 50mm/h, AI 위험 격자 사용, 현재 안전경로 알고리즘 기준  
계산 방식: `app.py`의 `get_route_points()`, `get_ai_predictions("50mm/h")`, `calculate_route_results(..., need_safe_route=True)`를 사용해 실제 경로 결과를 계산했다. 계산 시간은 경로 알고리즘 실행 시간 기준이며, Streamlit/Folium 화면 렌더링 시간은 제외했다.

50mm/h AI 예측 요약:
- 평균 AI 위험 확률: 56.42%
- 위험 격자 수: 128개
- AI 예측 로딩 시간: 약 1.33초

## 경로별 해석

강남역 -> 코엑스는 가장 균형이 좋다. 안전경로 거리가 0.43km만 증가하면서 평균 위험도가 14.83%p 낮아졌고, 최대 위험도도 99.01%에서 87.25%로 내려갔다. 고위험 구간도 10개 줄어든다. 경로선 차이가 크게 보여 제안서 캡처와 발표 설명에 모두 적합하다.

강남역 -> 삼성역은 평균 위험도는 낮아지지만, 안전경로의 고위험 구간 개수가 오히려 52개에서 55개로 늘어난다. "우회했지만 고위험 구간을 완전히 줄이지 못한 사례"로는 쓸 수 있으나 대표 경로로는 덜 적합하다.

압구정로데오역 -> 대치역은 안전경로가 매우 길어진다. 평균 위험도는 10.36%p 낮아지지만 거리 증가가 4.01km로 커서 추천 경로로 보여주기에는 부담이 있다. 고위험 경고 설명용으로는 가능하지만, 대표 시연 경로로는 비추천한다.

강남역 -> 대치역은 평균 위험도 감소 폭이 크지만, 안전경로에서도 최대 위험도가 96.55%로 매우 높고 고위험 구간 개수가 늘어난다. 안전경로의 한계를 설명하는 사례로는 가능하나, 제안서용 대표 캡처에는 적합하지 않다.

수서역 -> 강남역은 평균 위험도 감소 폭이 가장 크다. 다만 안전경로가 3.55km 길어져 발표 중 설명이 길어질 수 있다. 큰 우회와 위험도 감소를 보여주는 보조 시연 후보로 적합하다.

삼성서울병원 -> 강남역은 고위험 구간 회피 수가 27개로 가장 크다. 다만 안전경로에도 최대 위험도 97.63% 구간이 남아 있어 "대체 가능한 안전 도로가 부족해 일부 위험 구간이 포함되는 상황"을 설명하기 좋다.

## 추천 선정

제안서 대표 캡처용 경로:
- 강남역 -> 코엑스
- 이유: 거리 증가가 +0.43km로 작고, 평균 위험도 14.83%p 감소, 최대 위험도 하락, 고위험 구간 10개 회피가 모두 명확하다. 지도에서도 최단경로와 안전경로 차이가 잘 보인다.

발표 시연용 경로:
- 강남역 -> 코엑스
- 이유: 계산이 안정적으로 성공하고, 결과 해석이 쉽다. "조금 돌아가지만 위험도를 낮춘다"는 메시지가 가장 선명하다.

고위험 경고 확인용 경로:
- 삼성서울병원 -> 강남역
- 이유: 고위험 구간을 27개 줄이지만, 안전경로에도 매우 위험한 구간이 남아 경고 메시지 설명에 적합하다. 폭우 상황에서 모든 위험을 완전히 피할 수 없다는 현실적인 한계도 함께 보여줄 수 있다.

## 시연 경로 빠른 선택 프리셋 UI 의견

유용하다. 다만 지금 바로 추가하기보다는 제안서 제출 전 최종 캡처가 필요한 시점에 넣는 것이 좋다. 추천 프리셋은 너무 많이 두지 말고 다음 2~3개만 두는 편이 발표용으로 깔끔하다.

- 강남역 -> 코엑스: 대표 캡처 및 기본 시연
- 삼성서울병원 -> 강남역: 고위험 경고 확인
- 수서역 -> 강남역: 장거리 우회와 위험도 감소 보조 사례

프리셋 UI를 넣는다면 "시연 경로"라는 작은 selectbox 또는 버튼 형태가 좋다. 현재 기능을 바꾸지 않고도 출발지/도착지 selectbox 값을 빠르게 맞추는 보조 기능으로 설계하면 된다.
