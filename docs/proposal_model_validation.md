# RainGuard 모델 검증 설명

RainGuard는 강남구를 격자 단위로 나누고, 각 격자에 대해 폭우 상황에서의 침수 위험 확률을 예측하는 프로토타입이다. 모델은 RandomForest를 사용한다. RandomForest는 여러 개의 의사결정나무를 함께 사용해 예측하는 방식이라, 데이터 규모가 크지 않은 초기 프로토타입에서도 안정적으로 동작하고 feature importance를 통해 어떤 입력 변수가 예측에 영향을 주는지 설명하기 쉽다.

모델 입력 feature는 크게 네 그룹으로 구성했다. 첫째, `latitude`, `longitude` 같은 공간 위치 정보가 들어간다. 둘째, `rainfall_mm_h`로 10mm/h, 30mm/h, 50mm/h 강수량 시나리오를 반영한다. 셋째, `expected_stage`, `distance_to_flood_area_m`처럼 서울시 침수예상도 기반의 위험 정보를 사용한다. 넷째, `history_polygon_count`, `history_recent_polygon_count`, `history_year_count`, `history_recency_score`처럼 2022년과 2023년 침수흔적도에서 파생한 과거 침수 이력 정보를 사용한다. 출력값은 격자별 침수 위험 확률이며, 앱에서는 이 확률을 위험 격자와 안전경로 비용 계산에 활용한다.

검증은 랜덤 분할 검증과 공간 기반 검증을 함께 수행했다. 랜덤 분할 검증은 전체 격자 데이터를 학습/테스트로 나누어 기본 성능을 확인하는 방식이다. 이 결과 Accuracy 0.9673, Recall 1.0000, F1-score 0.9533, ROC-AUC 0.9808를 기록했다. 다만 랜덤 분할만 사용하면 가까운 지역의 유사한 격자가 학습과 테스트에 함께 포함될 수 있어 실제 미학습 지역에 대한 일반화 성능을 과대평가할 수 있다.

이를 보완하기 위해 공간 기반 검증을 추가했다. `spatial_east_holdout`은 longitude 기준으로 동쪽 일부 격자를 학습에서 제외하고 테스트 전용으로 사용한 방식이다. 이 검증에서는 Accuracy 1.0000, Recall 1.0000로 모든 지표가 1.0000에 가깝게 나왔다. 그러나 테스트 데이터 153개 중 양성 32개, 음성 121개인 특정 동쪽 영역이 비교적 쉬운 영역일 가능성이 있으므로, 이 결과를 대표 일반화 성능으로 단독 강조하지 않는다.

대표 공간 검증 결과로는 동서 4-band 검증 평균을 사용한다. 강남구 격자를 longitude 기준으로 west, mid-west, mid-east, east 네 개 band로 나눈 뒤, 한 번에 하나의 band를 테스트 영역으로 제외하고 나머지 세 개 band로 학습했다. 이 과정을 4회 반복해 평균 성능을 계산했다. 4-band 평균은 Accuracy 0.9587, Recall 0.9596, F1-score 0.9515, ROC-AUC 0.9838로, 공간적으로 분리된 미학습 지역에서도 랜덤 분할과 유사한 성능을 유지했다.

데이터 누수 점검도 함께 수행했다. `scenario_flood_label`, `scenario_risk_score`, `risk_grade`, `flood_label`처럼 정답 또는 정답에서 직접 파생된 컬럼은 모델 입력 feature에서 제외했다. `expected_stage`, `distance_to_flood_area_m`은 정답 생성 기준과 관련성이 큰 feature이므로 review 대상으로 따로 관리한다. 이는 공공 침수예상도와 실제 침수흔적도 기반 위험 정보를 활용하는 모델 특성상 해석에 주의가 필요한 부분이다.

침수 예측에서는 실제 위험 지역을 놓치지 않는 것이 중요하므로 Recall을 주요 지표로 본다. Accuracy가 높더라도 침수 위험 구역을 놓치면 서비스 목적에 맞지 않기 때문이다. 따라서 RainGuard는 Accuracy와 ROC-AUC도 함께 확인하되, 발표에서는 Recall과 공간 검증 결과를 함께 제시하는 것이 적절하다.

주의할 점은 현재 성능을 “실제 미래 침수를 96.73% 정확도로 예측한다”라고 표현하면 안 된다는 것이다. 현재 수치는 강남구 프로토타입 데이터셋과 강수량 시나리오 조건에서 수행한 검증 결과다. 실제 서비스 수준의 미래 예측 성능을 주장하려면 더 긴 기간의 침수흔적도, 실측 강수량, 배수시설, 지형, 도로 고도 등 추가 데이터와 외부 검증이 필요하다.

## 제안서 권장 표현

“RandomForest 모델은 프로토타입 데이터셋의 랜덤 분할 검증에서 Accuracy 0.9673, Recall 1.0000을 기록하였다. 또한 공간적으로 분리된 지역을 대상으로 한 동서 4-band 검증에서도 평균 Accuracy 0.9587, Recall 0.9596을 유지하여 미학습 공간에 대한 일반화 가능성을 확인하였다.”

## 피해야 할 표현

“실제 미래 침수를 96.73% 정확도로 예측한다.”

## 제안서용 해석

RainGuard의 모델 검증 결과는 강남구 공공데이터 기반 프로토타입에서 AI 침수 위험도 예측이 구현 가능하다는 근거로 사용한다. 최종 서비스 성능을 확정적으로 주장하기보다는, 침수예상도와 침수흔적도를 활용해 격자별 위험 확률을 산출하고 이를 안전경로 추천 비용에 반영할 수 있음을 보여주는 검증 자료로 해석한다.
