# RainGuard

RainGuard는 공공데이터 기반 도시 침수 위험 예측 및 안전 이동 경로 추천 Streamlit 웹앱입니다. 현재 구현 범위는 강남구 프로토타입이며, 폭우 상황에서 단순 최단경로가 아니라 침수 위험을 반영한 안전경로를 함께 비교하는 것을 목표로 합니다.

## 현재 기능

- 강수량 시나리오 선택: 10mm/h, 30mm/h, 50mm/h
- 서울시 침수예상도 SHP 레이어 표시
- 2022년, 2023년 침수흔적도 SHP 레이어 표시
- RandomForest 기반 AI 침수 위험 격자 표시
- 강남구 주요 지점 기반 출발지/도착지 선택
- 최단경로와 안전경로 계산 및 지도 비교
- 경로별 거리, 평균 위험도, 최대 위험도, 고위험 구간 수 비교
- 지도 스타일 선택과 무거운 레이어 조건부 로딩

## 활용 데이터

- 서울안전누리 안전정보지도 침수예상도
- 서울시 2022년, 2023년 침수흔적도
- 강남구 격자 데이터
- 강남구 도로망 데이터
- 강수량 시나리오 데이터

## AI 모델

모델은 RandomForest를 사용합니다. 입력 feature는 위치 정보, 강수량 시나리오, 침수예상도 단계, 과거 침수흔적 개수, 최근 침수 이력, 침수지역까지의 거리 등으로 구성됩니다. 출력은 격자별 침수 위험 확률이며, 지도 시각화와 안전경로 비용 계산에 활용됩니다.

## 모델 검증 결과

| 검증 방식 | Accuracy | Recall | F1-score | ROC-AUC |
| --- | ---: | ---: | ---: | ---: |
| 랜덤 분할 | 0.9673 | 1.0000 | 0.9533 | 0.9808 |
| 동서 4-band 공간 검증 평균 | 0.9587 | 0.9596 | 0.9515 | 0.9838 |

동쪽 지역 holdout은 모든 지표가 1.0000으로 나왔지만, 특정 영역이 비교적 쉬운 테스트 영역일 수 있으므로 대표 성능으로 과도하게 강조하지 않습니다. 자세한 검증 설명은 [`docs/proposal_model_validation.md`](docs/proposal_model_validation.md)를 참고하세요.

## 경로 추천 방식

최단경로는 도로 길이를 기준으로 계산합니다. 안전경로는 AI 침수 위험도를 도로 비용에 반영합니다.

```text
안전경로 비용 = 도로 길이 x (1 + alpha x AI 위험도)
```

강수량별 alpha 값은 다음과 같습니다.

- 10mm/h: 1.2
- 30mm/h: 2.0
- 50mm/h: 3.0

위험도가 높은 도로 구간은 추가 penalty를 적용해 우회 가능성을 높입니다.

## 현재 구현 범위와 향후 계획

현재는 강남구 주요 지점 selectbox 기반으로 경로를 선택합니다. 다음 단계에서는 지도 클릭으로 출발지와 도착지를 직접 선택하는 기능, 기상청 단기예보조회서비스 API 연동, 더 긴 기간의 침수흔적도 추가, 다른 자치구 확장을 진행할 예정입니다.
